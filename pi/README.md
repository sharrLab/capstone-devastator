# Berkas Raspberry Pi

Berkas yang berjalan di Raspberry Pi 3B+ (Ubuntu Server 24.04, ROS 2 Jazzy Base) akan ditambahkan di folder ini:

- `launch/`: rplidar_a2m12.launch.py, robot.launch.py, robot_nav.launch.py
- `scripts/`: nano_bridge.py, obstacle_avoider.py, scan_wifi_relay.py
- `udev/`: 98-nano.rules, 99-rplidar.rules
